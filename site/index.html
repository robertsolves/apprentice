Let your agent use the Mac like a careful person

apprentice lets a coding agent or a hosted model work any app on your Mac, or any website, for you. It reads the screen as a short numbered list, moves the real cursor, presses real keys, and proposes every change before it makes it.

How it works

One Swift binary, CLI and daemon in one, with no package dependencies. The agent calls it from its own shell; the daemon does the reading and the careful acting.

Reads text, not pixels

The accessibility tree becomes a numbered list of what's on screen. A step costs tens of tokens, not a screenshot. shot and ocr are there for the rare page that hides.

Real input only

Every click, scroll and keystroke goes through the system's own input stream, with the cursor on a curved path at a human pace. Nothing is injected into pages.

Proposes, then acts

Every command that changes something returns approve? and a token. Nothing happens until it's approved. Risky steps (send, delete, buy, passwords, settings) carry a ⚠.

Asks you

For decisions that are yours, a little window opens at the top of the screen: free text, choices, or "point at it". When you're away, the question goes back to the chat.

Stops for you

It waits until you've been idle. Touch a key or the mouse and it stops at once and leaves the cursor where you are. ctrl+opt+cmd+. is a kill switch.

Site rules built in

Per-site budgets, cooldowns, challenge hand-off and allowlists. Meta and TikTok are refused by default. They're part of the product, not add-ons.

Learns as it goes

Notes about apps and sites live in the repo. learn turns a task that worked into a flow, and do <flow> reruns it with one approval for the whole plan.

Fixes and updates itself

It runs from your own clone. Fixes are small commits that rebuild, self-test and restart. Upstream updates are rebased in, and a failed build keeps the old binary.

A Linux VM on the side

A small VM runs Chromium and any Linux app with its own screen, cursor and keyboard, so the agent works while you keep working. One VM per job, run side by side.

Works with your agent

The installer finds the assistants on your Mac and connects each one: a skill, a rules file, or the MCP server. There's also a built-in run loop for any OpenAI-compatible API.

Built for one person

apprentice is for a solo owner running a handful of tools and accounts at a pace they could keep up by hand. It's meant to bring the care of a bigger team, not more volume. Bulk outreach, mass following, scraping at volume and running several accounts on one site are out of scope on purpose.

Install

You need macOS 14 or later and Swift (Xcode or the command-line tools). One command installs it, and running it again updates:

git clone https://github.com/robertsolves/apprentice.git ~/.apprentice/src && ~/.apprentice/src/install.sh
  1. It builds a release binary, runs its self-test and installs it to ~/.local/bin/apprentice, signed so your permissions survive rebuilds.
  2. It connects every AI assistant it finds on your Mac.
  3. Grant Accessibility and Screen Recording to ~/.local/bin/apprentice in System Settings → Privacy & Security, then run apprentice stop.
